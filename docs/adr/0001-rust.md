# ADR-0001 — Rust como linguagem do serviço

**Status:** Aceita · **Data:** 2026-10-19

## Contexto
O serviço roda permanentemente na máquina do usuário, em três SOs, gerencia processos filhos, áudio em tempo real, WebSocket e um servidor HTTP. Precisa de baixo consumo em repouso e binário único.

## Decisão
Rust (edition 2021, toolchain estável), Cargo workspace com crates por domínio.

## Consequências
- (+) Baixo uso de memória/CPU; sem runtime externo; excelente ecossistema async (tokio), áudio (cpal), HTTP (axum/reqwest), MCP (rmcp).
- (+) Segurança de memória em código que lida com segredos e processos.
- (−) Curva de aprendizado e tempo de compilação maiores que Node/Python; UI nativa em Rust é fraca, resolvido pela ADR-0002.
